# 06 - Choose a Native Pattern

## Goal

Implement five interface needs with the HTML element that already matches the
required behavior.

## Tasks

1. Build the FAQ with `<details>` and `<summary>`.
2. Build the blocking delete confirmation with `<dialog>` and invoker commands.
3. Build the account menu with `popover`.
4. Build the short field explanation as inline help text.
5. Build documentation navigation with `<a>`.
6. Style open, focus, top-layer, and backdrop states.

No JavaScript is required. Test each interaction with keyboard only.
