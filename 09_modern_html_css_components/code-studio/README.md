# Lesson 09 Code Studio

Modern features are useful when they improve an interface without making the
baseline experience fragile. Work through the smaller labs before combining
them in the component library.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_feature_support` | Baseline first and `@supports` enhancement | 15 minutes |
| `02_nesting_refactor` | Native CSS nesting | 20 minutes |
| `03_scoped_component` | Scope roots, limits, and proximity | 20 minutes |
| `04_component_api` | Custom properties as a public API | 20 minutes |
| `05_theme_tokens` | `light-dark()` and `color-mix()` | 20 minutes |
| `06_native_patterns` | Details, dialog, popover, and links | 25 minutes |
| `07_anchored_hint` | Anchor positioning with a fallback | 20 minutes |
| `08_form_control_polish` | Native and custom form controls | 20 minutes |
| `09_component_library` | Integrated component workshop | 45 minutes |

Use a current browser for the modern enhancements. Also inspect every exercise
with the relevant enhancement temporarily disabled in DevTools.
