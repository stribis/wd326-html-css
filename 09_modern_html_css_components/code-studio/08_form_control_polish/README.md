# 08 - Form Control Polish

## Goal

Compare a low-cost native accent treatment with a fully custom checkbox that
rebuilds every important state.

## Tasks

1. Apply `accent-color` to the first checkbox and range input.
2. Apply `appearance: none` only to `.custom-control`.
3. Rebuild unchecked, checked, focus-visible, and disabled states.
4. Keep the label clickable and the control at least 24 by 24 CSS pixels.
5. Add a CSS comment explaining whether the custom version earns its cost.
