# 09 - Build a Tiny Component Library

## Goal

Combine the lesson into a small component board that stays semantic and usable
without JavaScript.

## Required Features

1. Refactor one component with native CSS nesting.
2. Add one theme area with `@scope`.
3. Expose at least three custom properties as a component API.
4. Keep the disclosure, popover, and dialog native.
5. Anchor the help popover with a readable fallback.
6. Use adaptive color tokens and one `color-mix()` value.
7. Polish the checkbox, select, focus, open, and backdrop states.

## Completion Check

Test keyboard access, light and dark schemes, 200% zoom, a narrow viewport, and
the page with each progressive enhancement temporarily disabled.
