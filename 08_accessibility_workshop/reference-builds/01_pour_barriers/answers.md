# POUR Barrier Answers

| Barrier | Primary principle | Common overlap | Concrete repair |
| --- | --- | --- | --- |
| Missing captions | Perceivable | Understandable | Add synchronized captions and transcript |
| Keyboard trap | Operable | Robust | Use native control behavior and provide an exit |
| Unclear error | Understandable | Perceivable | Identify field, requirement, and correction |
| Broken name | Robust | Understandable | Supply a programmatically determinable name |
| Color-only status | Perceivable | Understandable | Add text or another non-color cue |
| Hover-only menu | Operable | Perceivable | Add keyboard and touch access |
| Unexpected context | Understandable | Operable | Require explicit action or warn first |
| Invalid ARIA | Robust | Operable | Use native HTML or a valid ARIA pattern |
