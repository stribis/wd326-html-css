Lesson 08

POUR Barrier Answers

Perceivable

Missing captions

Add synchronized captions and a transcript for spoken and meaningful audio.

Operable

Keyboard trap

Use native controls or implement documented keyboard behavior, including a way to leave.

Understandable

Unclear error

Name the field, explain the requirement, and describe how to correct it.

Robust

Broken name

Use visible text or provide the native button with an accessible name.

Perceivable

Color-only status

Add text or an icon with text alternative in addition to color.

Operable

Hover-only menu

Expose the same content through keyboard and touch interaction.

Understandable

Unexpected context

Require an explicit action or warn users before the context change.

Robust

Invalid ARIA

Prefer a native element or implement a valid role, state, and property contract.
