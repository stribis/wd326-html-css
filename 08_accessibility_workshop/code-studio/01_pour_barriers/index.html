Lesson 08

Match the Barrier to POUR

  1. Missing captions: A tutorial video contains important spoken instructions.
  2. Keyboard trap: Focus enters a custom widget but cannot leave with Tab or Escape.
  3. Unclear error: A form reports only "Invalid input" after submission.
  4. Broken name: An icon button has no accessible name in the accessibility tree.
  5. Color-only status: Sold-out sessions are communicated only with red text.
  6. Hover-only menu: Important navigation appears only when a pointer hovers.
  7. Unexpected context: Selecting an option immediately opens a new page without warning.
  8. Invalid ARIA: A custom control uses a role with unsupported attributes.
