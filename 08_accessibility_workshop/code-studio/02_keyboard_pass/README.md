# 02 - Artist Website Keyboard Pass

## Goal

Audit the artist website using only Tab, Shift+Tab, Enter, Space, and arrow keys.

## Tasks

1. Reach every interactive element in a logical order.
2. Record anything that cannot be reached or activated.
3. Record every point where focus is hidden or unclear.
4. Check whether repeated navigation can be skipped.
5. Repair the HTML and CSS without adding JavaScript.
6. Document the issue, affected users, repair, and retest in `audit.md`.

You may run the same pass on your own continuing artist project after repairing
the supplied example.
