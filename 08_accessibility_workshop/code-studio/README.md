# Lesson 08 Code Studio

Accessibility is practiced as a repeatable manual workflow rather than a final
automated score.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_pour_barriers` | Classify barriers with POUR | 15 minutes |
| `02_keyboard_pass` | Audit the continuing artist website | 20 minutes |
| `03_outline_repair` | Landmarks, headings, and skip navigation | 20 minutes |
| `04_name_audit` | Links, buttons, images, and form names | 20 minutes |
| `05_contrast_zoom` | Contrast, color-only meaning, zoom, and reflow | 20 minutes |
| `06_form_repair` | Labels, hints, errors, and autocomplete | 25 minutes |
| `07_pointer_pass` | Target size and alternatives to precision gestures | 20 minutes |
| `08_accessibility_audit` | Full manual audit and repair sprint | 40 minutes |

Audit manually before revealing hints or opening the reference builds.
