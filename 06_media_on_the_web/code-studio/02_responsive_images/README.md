# 02 - Responsive Image Decision

## Goal

Implement resolution switching, art direction, and a CSS background fallback,
then explain why each uses a different mechanism.

## Tasks

1. Add a three-candidate `srcset` to the first image.
2. Add an accurate `sizes` value for its rendered width.
3. Add a portrait source for narrow screens inside the `picture` element.
4. Keep the wide `img` as the accessible fallback and source of `alt` text.
5. Add a normal JPEG `background-image` before an `image-set()` enhancement.
6. Explain resolution switching versus art direction in `answers.md`.

Use the supplied local files; do not rename them.
