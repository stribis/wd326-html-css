Format Triage

Pick a preferred delivery format and justify it in answers.md.

01

Portfolio hero

Large photograph, no transparency, quality matters, many mobile visitors.

02

One-color logo

Must scale cleanly and inherit the site's current color.

03

App screenshot

Sharp UI text with transparent rounded corners.

04

Concert loop

Eight seconds of realistic motion, silent, intended to repeat.

05

Animated sticker

Small graphic animation with transparency and a limited palette.

06

Hero fallback

Modern compressed photo plus a format for older or constrained tooling.
