# 01 - Format Triage

## Goal

Choose media formats by content, required features, quality, and delivery cost.

## Tasks

Complete `answers.md` for these scenarios:

1. A large photographic portfolio hero with no transparency.
2. A one-color logo that must scale to any size and follow CSS color.
3. An app screenshot with sharp text and transparency.
4. An eight-second looping concert clip with realistic motion.
5. A small animated sticker with transparency.
6. A photographic hero that needs a conservative fallback.

For each answer, name the preferred format, any fallback, and the deciding
constraint. More than one answer may be defensible when the reasoning is sound.
