# Lesson 06 Code Studio

Each media topic has a focused exercise with inspectable files and browser
behavior.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_format_triage` | Select formats from project constraints | 15 minutes |
| `02_responsive_images` | `srcset`, `sizes`, `picture`, and CSS fallbacks | 30 minutes |
| `03_performance_pass` | Dimensions, priority, lazy loading, and decoding | 20 minutes |
| `04_svg_icon_pass` | Inline SVG, `viewBox`, `currentColor`, and names | 20 minutes |

The existing background-image and external SVG demonstrations remain untouched
in `01_background` and `02_svgs`.
