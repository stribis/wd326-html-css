# Format Triage Answers

| Scenario | Preferred format | Fallback | Deciding constraint |
| --- | --- | --- | --- |
| Portfolio hero | AVIF or WebP | JPEG | Photographic compression and client support |
| One-color logo | SVG | PNG only for legacy delivery needs | Vector scaling and CSS color |
| App screenshot | PNG or lossless WebP | PNG | Sharp edges and transparency |
| Concert loop | WebM and MP4 video | Static poster | Realistic motion compression |
| Animated sticker | Animated WebP | GIF where required | Animation and alpha transparency |
| Hero fallback | AVIF/WebP source | JPEG img fallback | Progressive format support |
