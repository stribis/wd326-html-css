Lesson 06

Format Triage

One defensible set of choices.

AVIF or WebP

Portfolio hero

Modern photographic compression; provide a JPEG fallback when project support requires it.

SVG

One-color logo

Vector scaling, tiny geometry, transparency, and CSS color control.

PNG or lossless WebP

App screenshot

Preserves sharp edges and transparency without JPEG artifacts.

WebM/MP4 video

Concert loop

Video codecs handle realistic motion far more efficiently than GIF.

Animated WebP

Animated sticker

Animation plus alpha transparency; GIF can be a legacy fallback.

AVIF/WebP plus JPEG

Hero fallback

Use picture sources for modern formats and a widely compatible JPEG img fallback.
