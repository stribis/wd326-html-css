# 02 - Recreate Three Tables

## Goal

Complete three tables whose structure matches the relationships in their data.

## Tasks

1. Add a descriptive caption to every table.
2. Complete column headers in the feature comparison.
3. Use row headers with `scope="row"` in the workshop schedule.
4. Complete `thead` and `tbody` groups where appropriate.
5. Right-align numeric cells without right-aligning their labels.
6. Style headers and zebra rows without removing table semantics.

## Completion Check

Read each table row by row. Every value should still have an understandable
header relationship without relying only on color or visual position.
