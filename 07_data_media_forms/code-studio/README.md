# Lesson 07 Code Studio

The exercises progress from media and structured data into complete forms.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_media_embed` | Video, audio, captions, poster, and transcript | 20 minutes |
| `02_table_recreation` | Comparison, schedule, and numeric tables | 30 minutes |
| `03_responsible_iframe` | Titles, aspect ratio, lazy loading, and sandbox | 15 minutes |
| `04_form_foundations` | Form, labels, controls, grouping, and submission | 30 minutes |
| `05_validation_pass` | Native constraints and understandable states | 20 minutes |
| `06_form_styling` | Consistent controls, focus, checked, and disabled states | 25 minutes |

The existing `01_tables` and `02_iframes` files remain available as earlier
demonstrations.
