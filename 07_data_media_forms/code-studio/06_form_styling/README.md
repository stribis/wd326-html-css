# 06 - Form Styling

## Goal

Create a coherent visual system for native controls without hiding their states
or reducing their usability.

## Tasks

1. Use inherited font styles on all controls.
2. Give text-like controls consistent width, padding, border, and background.
3. Keep labels visually connected to their controls.
4. Style hover and `:focus-visible` separately.
5. Use `accent-color` for radio buttons and checkboxes.
6. Style disabled controls so they remain identifiable and readable.
7. Style the file-selector button without hiding the file input.
8. Keep every control and button at least 44px high where practical.

## Completion Check

Use keyboard navigation, select a radio and checkbox, choose a file, and compare
enabled and disabled controls. No state should rely on color alone.
