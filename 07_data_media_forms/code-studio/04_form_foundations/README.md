# 04 - Form Foundations

## Goal

Repair a booking form so every value can be understood, entered, grouped, and
submitted using native HTML.

## Tasks

1. Give the form a useful `action` and `method="get"` for this static demo.
2. Connect every visible label with `for` and `id`.
3. Give every submitted control a unique `name`.
4. Choose appropriate types for email, phone, URL, date, time, number, range,
   color, and file inputs.
5. Group ticket radio buttons with `fieldset` and `legend`.
6. Keep the newsletter checkbox independent.
7. Add a select menu and message textarea.
8. Make the submit button explicitly `type="submit"`.
9. Add useful `autocomplete` values where standardized tokens exist.

## Completion Check

Submit the form and inspect the query string on `success.html`. Every expected
field should have a meaningful parameter name.
