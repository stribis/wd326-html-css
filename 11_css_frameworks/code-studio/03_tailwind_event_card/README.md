# 03 - Tailwind Event Cards

## Goal

Use Tailwind CSS 4 utilities, state variants, responsive variants, and theme
tokens to recreate the same event interface.

## Tasks

1. Define named studio, paper, ink, and accent colors with `@theme`.
2. Compose the page layout directly in the HTML classes.
3. Build three equal-height event cards and bottom-align their actions.
4. Include hover, `focus-visible`, and disabled variants.
5. Build a labelled form that stacks before the medium breakpoint.
6. Compare the finished HTML with the Bootstrap build.

The Play CDN is for this classroom exercise only, not production deployment.
