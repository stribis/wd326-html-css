# 02 - Bootstrap Event Cards

## Goal

Use Bootstrap 5.3 layout, component, spacing, type, image, form, state, and
responsive classes to build the event interface.

## Tasks

1. Create a centered container and a strong page header.
2. Build a responsive row of three equal-height cards.
3. Make images fluid and preserve their aspect ratio.
4. Style links and the disabled action with button classes.
5. Build a labelled email form with a useful narrow-screen layout.
6. Preserve semantic HTML and visible keyboard focus.

Bootstrap JavaScript is not included because this page uses no Bootstrap
component that requires it.
