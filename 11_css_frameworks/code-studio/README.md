# Lesson 11 Code Studio

Build the same interface with two different framework philosophies, then choose
based on project constraints rather than popularity.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_framework_choice` | Match tools to project constraints | 20 minutes |
| `02_bootstrap_event_card` | Components, layout, and utilities | 25 minutes |
| `03_tailwind_event_card` | Utility composition and theme tokens | 25 minutes |
| `04_framework_showdown` | Build, compare, and defend a choice | 45 minutes |

The classroom examples use the official CDN setup for speed. Production work
should normally use a package manager and build process so versions are locked
and unused Tailwind utilities can be generated ahead of time.
