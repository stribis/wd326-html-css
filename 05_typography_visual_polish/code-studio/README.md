# Lesson 05 Code Studio

Lesson 05 is divided into short exercises so each visual-polish topic gets an
immediate application.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_relative_paths` | Navigate a nested project tree | 15 minutes |
| `02_typography_tune_up` | Type scale, measure, rhythm, and `clamp()` | 25 minutes |
| `03_font_loading` | Online service versus self-hosted font | 20 minutes |
| `04_gradient_flags` | Hard-stop gradients and pseudo-elements | 30 minutes |
| `05_icon_button_states` | Inline SVG, accessible names, and states | 20 minutes |

The existing `01_flags` and `02_icons` examples remain available as the original
classroom demonstrations.
