# 04 - Gradient Flag Challenge

## Goal

Recreate six recognizable flags using HTML, CSS gradients, and pseudo-elements.
Do not use image files, SVG, canvas, or JavaScript.

## Tasks

1. Colombia: unequal horizontal bands.
2. Italy: equal vertical bands.
3. Zimbabwe: seven bands, bordered white triangle, and red star marker.
4. Tanzania: diagonal green and blue fields separated by yellow and black.
5. United States: thirteen stripes, blue canton, and a repeated star pattern.
6. Switzerland: square field with a correctly proportioned centered cross.

## Completion Check

- All six flags fit in the page grid without overflow.
- Every rectangular flag keeps a stable `3 / 2` aspect ratio.
- Switzerland remains square.
- Decorative flag details are hidden from assistive technology.

Approximation is acceptable, but the geometry should be deliberate and
recognizable.
