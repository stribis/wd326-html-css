# 02 - Typography Tune-Up

## Goal

Turn an unstructured block of text into a small, consistent type system.

## Tasks

1. Define CSS variables for body and display font stacks.
2. Define at least four related font-size steps.
3. Apply a comfortable body `line-height`.
4. Limit long paragraphs to approximately `60-70ch`.
5. Use `clamp()` for the main heading with clear minimum and maximum values.
6. Style labels with weight, case, and spacing without changing their HTML text.
7. Keep paragraphs left-aligned and verify text contrast.

## Completion Check

Resize the browser and explain when the `clamp()` minimum, preferred value, and
maximum are active. Zoom to 200% and confirm that text remains readable.
