# Lesson 10 Code Studio

Motion should communicate, orient, or add carefully controlled atmosphere. The
labs move from analysis to transforms, transitions, keyframes, and a creative
build.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_motion_audit` | Purpose, triggers, cost, and reduced motion | 20 minutes |
| `02_transform_warm_up` | Translate, rotate, scale, order, and origin | 20 minutes |
| `03_transitions_lab` | State changes, easing, and explicit properties | 30 minutes |
| `04_animation_site` | Purposeful keyframes in a realistic page | 35 minutes |
| `05_css_clock` | Rotation, transform origin, and `steps()` | 35 minutes |
| `06_animated_scene` | Coordinated multi-element animation | 50 minutes |

Use DevTools to inspect running animations. Every build must also have a useful
`prefers-reduced-motion` mode.
