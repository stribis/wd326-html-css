# 01 - Motion Audit

## Goal

Audit an intentionally over-animated event page before changing its CSS.

## Tasks

1. Complete one row in `audit.md` for every animation.
2. Identify its trigger, purpose, duration, repetition, and affected properties.
3. Decide whether to keep, simplify, pause, or remove it.
4. Repair the CSS based on your audit.
5. Add a reduced-motion mode that preserves important state information.

Animations are not automatically bad. The question is whether each one earns
the attention and performance cost it creates.
