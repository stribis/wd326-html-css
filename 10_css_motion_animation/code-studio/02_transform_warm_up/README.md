# 02 - Transform Warm-Up

## Goal

Practice transform functions and individual transform properties while keeping
the surrounding layout stable.

## Tasks

1. Translate the first tile 18px right and 10px up.
2. Rotate the second tile 8 degrees.
3. Scale the third tile to 1.12 without changing its layout space.
4. Rotate the fourth tile around its lower-left corner.
5. Give the final two tiles the same functions in opposite order and compare.
6. Confirm that neighboring tiles do not reflow.
