# Lesson 12 Code Studio

Start with the browser platform, then add Sass where compile-time organization
or generation provides a concrete benefit.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_native_css_refactor` | Tokens, layers, nesting, and fluid values | 20 minutes |
| `02_module_repair` | Replace `@import` with `@use` and `@forward` | 25 minutes |
| `03_style_system` | Build and compile a small modular Sass system | 45 minutes |

For Sass projects, run `npm install` once and use the scripts documented inside
the exercise. Do not commit `node_modules`.
