# Lesson 02 Code Studio

These exercises move from choosing precise selectors to styling the continuing
Nova Vale artist profile.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_selector_scavenger` | Basic, combinator, attribute, and modern selectors | 25 minutes |
| `02_artist_profile_css` | Cascade, layers, units, and interaction states | 45-60 minutes |

Try the selector hunt without changing its HTML. In the artist-profile workshop,
keep the supplied HTML unchanged for the first 20 minutes so selector choice
remains part of the problem.
