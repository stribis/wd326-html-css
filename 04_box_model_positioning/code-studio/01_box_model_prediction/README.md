# 01 - Box Model Prediction

## Goal

Calculate each rendered width before checking it in DevTools.

## Tasks

1. Read the CSS for Boxes A-D.
2. Write a width calculation in every blank answer.
3. Decide which parts are inside the declared width.
4. Inspect each `.box` in DevTools and compare the rendered width.
5. Add the global `border-box` reset and record which answers change.

Assume the browser root font size is `16px`.

## Questions

- Is margin part of an element's rendered width?
- Why does Box C exceed half of its parent?
- What limits Box D in the narrow container?
