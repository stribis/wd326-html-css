# Lesson 04 Code Studio

These exercises make sizing and positioning observable before applying both to
the continuing artist profile.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_box_model_prediction` | Calculate content-box and border-box dimensions | 20 minutes |
| `02_positioning_drills` | Relative, absolute, fixed, sticky, and inset | 30 minutes |
| `03_artist_profile_polish` | Apply spacing, sizing, and positioning safely | 35 minutes |

Use the Box Model panel and Layout tools in browser DevTools to verify every
prediction. Guessing is not a debugging method.
