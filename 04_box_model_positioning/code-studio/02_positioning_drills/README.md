# 02 - Positioning Drills

## Goal

Complete six visible positioning tasks and identify the coordinate system used
by each positioned element.

## Tasks

1. Pin `.badge` to the top-right of its own card.
2. Move `.relative-note` visually while preserving its original flow space.
3. Pin `.overlay` to all four edges of the poster with `inset`.
4. Make `.sticky-title` stick below the top edge while its section scrolls.
5. Fix the escaped badge in `.broken-card` by creating the correct containing block.
6. Attach `.back-to-top` to the viewport's bottom-right corner.

## Completion Check

For every task, explain whether the element is positioned relative to itself,
an ancestor, its scroll container, or the viewport. Test the page by scrolling.
