# 02 - Artist Profile Flex Layout

## Goal

Apply the Flexbox patterns from the drills to the Nova Vale artist profile.
Base visual styling is provided so the work can focus on layout.

## Tasks

1. Put the logo and navigation on one line and push navigation to the right.
2. Make the navigation links a flex row with a consistent gap.
3. Let the hero text and figure share a row and wrap naturally.
4. Build the release card as a wrapping media object.
5. Make the show cards share the available width and wrap.
6. Make each show card a column and align its ticket link at the bottom.
7. Prevent the logo and release artwork from shrinking unexpectedly.
8. Use `gap` for spacing between flex items.

## Completion Check

Test at wide and narrow widths. Content must remain in logical source order,
navigation must remain usable, and no horizontal scrolling should appear.
