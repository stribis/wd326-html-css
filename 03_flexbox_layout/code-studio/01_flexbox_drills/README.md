# 01 - Flexbox Drills

## Goal

Complete eight small Flexbox tasks on one page. Edit only `styles.css`.

## Tasks

1. Place the logo and navigation on one row.
2. Push the Account link to the far side with an auto margin.
3. Prevent the logo from shrinking.
4. Make the topic tags wrap onto additional lines.
5. Turn the album preview into an image-and-text media object.
6. Make the three cards share available width and wrap when necessary.
7. Align every card button to the bottom of its card.
8. Move item B to the cross-axis end using `align-self`.

## Completion Check

- Every `display: flex` is on the parent whose direct children need layout.
- Spacing between flex items uses `gap`.
- The page remains readable in a narrow browser window.
- Source order remains logical; do not use `order` to repair the HTML.

## Stretch

Change the card basis and explain exactly when the cards wrap.
