# Lesson 03 Code Studio

The first exercise isolates Flexbox patterns. The second applies the same
patterns to the continuing Nova Vale profile.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_flexbox_drills` | Container and item properties in small patterns | 35 minutes |
| `02_artist_profile_flex` | Navigation, media objects, wrapping cards | 45 minutes |

The older `01_flex_basics` and `02_flex_website` examples remain in the lesson
folder for live classroom demonstrations.
