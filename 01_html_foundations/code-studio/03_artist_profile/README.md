# 03 - Artist Profile

## Goal

Build the semantic HTML foundation for the Nova Vale artist site. This page will
be styled and laid out in later lessons, so strong structure matters now.

## Tasks

1. Complete the missing page landmarks: header, navigation, main, and footer.
2. Create a logical heading hierarchy beginning with the artist name.
3. Mark up the hero image and caption as a figure.
4. Create About, Latest Release, and Shows sections.
5. Mark up the release as an independent article.
6. Mark up each show as an article and each date with `time`.
7. Write descriptive link text and useful image alternative text.
8. Keep every supplied sentence and link in the finished page.

## Completion Check

- Navigation links reach all three content sections.
- The page has one `main` landmark and one `h1`.
- Every section has a heading.
- Both images have dimensions and purposeful alternative text.
- Show dates include machine-readable `datetime` values.
- The document passes the W3C HTML validator.

## Stretch

Add metadata for the page description and label the primary navigation.
