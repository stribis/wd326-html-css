# 02 - Build Your First Page

## Goal

Complete a small, valid HTML document from the incomplete starter.

## Tasks

1. Add the HTML doctype.
2. Set the document language to English.
3. Add UTF-8 character encoding and the responsive viewport setting.
4. Give the browser tab a useful title.
5. Add a site heading and a short introductory paragraph.
6. Add the supplied cat image with useful alternative text and dimensions.
7. Add a navigation list linking to the two sections on the page.
8. Add an About section and a Contact section with correct headings.

## Completion Check

- Internal navigation links move to the correct sections.
- The page has exactly one `h1` and a logical heading order.
- The image has `src`, `alt`, `width`, and `height` attributes.
- The W3C HTML validator reports no errors.

## Stretch

Add a footer with your name and the current year.
