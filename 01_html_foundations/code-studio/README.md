# Lesson 01 Code Studio

Work through these exercises in order. They move from repairing an existing
document to creating the HTML foundation for the artist profile used in later
lessons.

| Exercise | Focus | Suggested time |
| --- | --- | ---: |
| `01_semantic_rewrite` | Landmarks, headings, links, images | 15 minutes |
| `02_first_page` | Boilerplate and fundamental elements | 15 minutes |
| `03_artist_profile` | Complete semantic page structure | 30-40 minutes |

Open each folder's `README.md` before editing its `index.html`. Use the HTML
validator and browser DevTools after each exercise.

The exercises intentionally contain no visual CSS. In this lesson, meaning and
document structure are the design work.
